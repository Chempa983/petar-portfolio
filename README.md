# Petar Dojčinović – Personal Portfolio

A responsive, bilingual Swedish/English personal portfolio built from three earlier sites.

## Files
- `index.html` – Swedish page (self-contained CSS & JavaScript)
- `index-en.html` – English page (self-contained CSS & JavaScript)
- `assets/portfolio.css` and `assets/portfolio.js` – maintainable source versions

## Deploy on GitHub Pages
Copy `index.html` and `index-en.html` into the root of your `petar-portfolio` repository and retain your existing `Petar_Dojcinovic_CV.pdf`, `diplom-petar-dojcinovic.pdf`, and `certifikat-petar-dojcinovic.pdf` files. HTML files already contain their CSS and JavaScript and do not depend on `assets` to render.

## Content checks before publication
Verify job dates, locations, achievements, Empiri X3 module description, contact details, certificate date, and CV. Outcomes without measured data are identified as initiatives or concepts.

## Quality checks
HTML content, anchor references, project filters (source-reviewed), JavaScript syntax (`node --check`), and missing section targets were checked. Browser-based preview was blocked by sandbox policy; cross-browser visual QA remains to be performed.
